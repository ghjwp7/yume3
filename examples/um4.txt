um4's "Clip URL → browser" button gets a URL from the clipboard, via
"xclip -o".  It deletes any newlines within the URL (for details of
how, see um4) and opens the URL in user-selected browser.

For example, if you copy or select URL text like https://www.google.com
and then click the "Clip URL → browser" button, program xdg-open will
attempt to open the URL's webpage in user-selected browser.

If you copy or select an ebay item number like 227364381941 and then
click the "Ebay# → browser" button, the menu creates a URL
like the following, and tries to open the URL:
    http://cgi.ebay.com/ws/eBayISAPI.dll?ViewItem&item=227364381941

In linux, text selection can be done by "left drag" as follows:
Move mouse cursor to first or last letter of text to be selected.
Press left mouse button.  Move mouse cursor to other end of text.
Release left mouse button.

In linux, text highlighted by left drag can be pasted as follows: Move
mouse cursor to paste location.  Click the middle mouse button.
